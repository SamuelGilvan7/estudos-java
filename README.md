
# 🛒 Gerenciador de Produtos (Java)

Projeto desenvolvido no âmbito dos meus estudos de programação em Java, com foco em lógica de programação, Orientação a Objetos (POO) e manipulação de estruturas de dados.

## 🚀 Sobre o Projeto
O **Gerenciador de Produtos** é uma aplicação em consola (CLI) que permite realizar operações básicas de gestão de inventário, servindo para praticar conceitos fundamentais da linguagem Java.

## 🛠️ Tecnologias Utilizadas
* **Java** (JDK 17+)
* **IntelliJ IDEA**
* **Git e GitHub** para controle de versão

## 📋 Funcionalidades
* Cadastro de novos produtos (com atributos como ID, nome, preço e quantidade).
* Listagem de produtos cadastrados.
* Organização estruturada com classes e encapsulamento.

## 📂 Estrutura do Projeto
```text
src/
└── main/
    └── java/
        └── org/
            └── example/
                ├── Main.java      # Classe principal com a lógica de execução e menu
                └── Produto.java   # Classe modelo que representa o produto (POO)

```
## 💻 Como Executar

1. Certifica-te de ter o JDK instalado na tua máquina.

2. Clona este repositório:

```bash
git clone https://github.com/SamuelGilvan7/estudos-java.git
```
3. Abre o projeto no teu ambiente de desenvolvimento favorito (ex: IntelliJ IDEA).

4. Executa a classe Main.java.
